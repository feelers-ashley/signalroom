# Signal Room

Three live activities for Workshop 2 (Fireflies, Steersman, Two Rooms). Students join on their phones; no accounts.

1. Paste the class Firebase config into `config.js`.
2. Push this folder to a GitHub repo and turn on **Settings → Pages** (branch `main`, root).
3. Projector: open `https://YOUR-USERNAME.github.io/signal-room/?host`
   Students: open the same address without `?host` (the lobby shows a QR code).

Rehearse without Firebase: leave the placeholder config, run a local server, open one tab with `?host` and a few tabs without. That is local mode.
